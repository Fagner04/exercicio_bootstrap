"Informações"

HTML
O que o HTML faz?
Estrutura o conteúdo de páginas da internet. Define elementos como títulos, parágrafos, imagens, links, formulários, entre outros. Funciona como um “esqueleto” que o navegador interpreta para exibir o site corretamente. Por exemplo, quando você vê um botão “Criar Conta” ou um campo para digitar seu nome, tudo isso foi construído com HTML.
CSS
🎨 O que o CSS faz?
Define o visual de uma página web: cores, fontes, tamanhos, espaçamentos, bordas, animações e muito mais. Separa o conteúdo (HTML) da apresentação (CSS), deixando o código mais limpo e fácil de manter. Permite que um único arquivo controle o estilo de várias páginas ao mesmo tempo.
JAVASCRIPT
⚡ O que o JavaScript faz?
Torna páginas interativas: cliques, animações, validações de formulário, menus dinâmicos, etc. Permite atualizar conteúdo sem recarregar a página (como em chats ou redes sociais). Pode ser usado tanto no navegador (front-end) quanto no servidor (back-end) com ferramentas como Node.js...
